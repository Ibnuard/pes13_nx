# FEXTendo / PES13 NSP forwarder

The forwarder launches the existing SD installation at
`sdmc:/switch/pes13-fex/pes13-fex.nro`.

| Setting | Value |
| --- | --- |
| HOME menu name | PES13 - FEXTendo |
| Publisher | AndroSwitch Project |
| Display version | 0.3.7 |
| Title ID | `05b0354496b71000` |
| Address space | 32-bit, no alias (`AddressSpaceType = 2`) |
| CPU permissions | Four cores: IDs 0, 1, 2, 3 |
| svcDebug | Disabled / false |
| Icon | Exact JPEG bytes extracted from the v3.6 port-cleanup NRO |

Install `FEXTendo-PES13-32bit-noalias-4core-svcdebug-off.nsp` with the
homebrew NSP installer already used on your Switch. Then launch
**PES13 - FEXTendo** from HOME. Keep the NRO and the complete FEXTendo runtime
on the SD card at the path above. This NSP contains the forwarder only.

The address-space setting controls virtual memory layout. The forwarder and
native runtime still execute AArch64 code. It does not change anti-aliasing
or other game graphics options.

`svcDebug = false` matches Sphaira's **Disabled** option: `force_debug = false`
and `allow_debug = false`, with its legacy `force_debug_prod = true` retained.
The debug capability word is `0x0004ffff` in both ACI0 and ACID; the newer
force-debug bit at bit 19 is clear. Debug-related syscall permissions are
inherited from the homebrew loader. The four-core descriptor is `0x030073f7`.

## Verification

`build.json` records the NSP, NRO and icon SHA-256 hashes and the decoded
NPDM capabilities. `verification.json` records independent extraction and
hash verification using hactool, including the packaged NPDM, NRO path,
icon, executable and content metadata. Nintendo's retail signatures are
absent, as expected for this homebrew forwarder; content hashes and the
packer-generated program signature are checked separately.

Installation and launching on a physical Switch have not been tested.

## Source and rebuild

The loader is compiled from
[Sphaira hbl at 72a94b9](https://github.com/NaGaa95/sphaira/tree/72a94b905816de24817594109fb012a8f7107d8c/hbl),
which derives from nx-hbloader. The forwarder settings follow
[Sphaira's NPDM configuration](https://github.com/NaGaa95/sphaira/blob/72a94b905816de24817594109fb012a8f7107d8c/sphaira/source/owo.cpp).
The package includes the loader source and Sphaira, nx-hbloader and libnx
license notices. Source is compiled without loader code changes; NPDM
settings and the title ID are generated by the build script.

Packing uses
[rlaphoenix/hacBrewPack at 745b16e](https://github.com/rlaphoenix/hacBrewPack/tree/745b16ecfc9ce055743067d200572204cb2aac6c),
derived from The-4n's hacBrewPack. The title ID uses Sphaira's deterministic
hash of `/switch/pes13-fex/pes13-fex.nro` plus the same argument string.

With those revisions checked out under `local/forwarder-tools/`, build the
packer using `cp config.mk.template config.mk` and `make CC=cc` in its folder.
Use the project's existing devkitA64/libnx toolchain and place the libnx
license at `local/forwarder-tools/libnx-LICENSE.md`. From the repository root:

```sh
python3 -B tools/build-fextendo-forwarder.py --keys /path/to/your/prod.keys
```

The builder accepts `--nro`, `--sphaira`, `--packer`, `--libnx-license`,
`--work` and `--out` overrides. The default NRO is the checked v3.6
port-cleanup executable. Keys are used locally for packing, with temporary
key material removed afterwards; they are never included in the output.
